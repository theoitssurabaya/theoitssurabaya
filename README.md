I am a 6th-semester **Computer Engineering** student at **Institut Teknologi Sepuluh Nopember (ITS)** with a deep passion for bridging the gap between hardware and intelligence. My work focuses on **Internet of Things (IoT)**, **Embedded Systems**, and **Edge AI**.

### 📂 Featured Projects:

#### 🌱 [Smart Irrigation System](https://github.com/theoitssurabaya)
An Edge AI prototype using **Raspberry Pi 4B** and a **Random Forest** model to provide automated watering recommendations. The hardware was custom-designed using **AutoCAD Fusion**.

#### 💧 [Smart Dispenser IoT Ecosystem](https://github.com/theoitssurabaya)
A precise water management system built with **ESP32** and **Load Cells**, integrated with a **Flutter** mobile application for real-time monitoring.

A real-time protection system using **PZEM-004T** sensors and a **K-Nearest Neighbors (KNN)** classification model to detect and prevent electrical anomalies via **MQTT** and **Node-RED**.

#### 🎯 [Distance Target Game](https://github.com/theoitssurabaya)
A full-stack IoT project synchronizing physical ultrasonic measurements with a **Node.js** and **MySQL** web application.
